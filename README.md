## 🚀 Featured Projects

### 📧 gmail-notification
*An automated, lightweight pipeline for personal daily email management.*

**Overview:** This project connects to the Gmail API to fetch unread emails, automatically summarizes their contents, and pushes brief notifications to my devices so I never miss important updates.

**Tech & Architecture:**
- **Core:** Python (or your language of choice), Gmail API
- **Deployment:** Hosted on a free-tier Google Cloud Platform (GCP) E2 instance.
- **Automation:** Scheduled via a Linux `cronjob` to run every 3 hours.
- **Alerting:** Uses `ntfy.sh` for seamless push notifications.
